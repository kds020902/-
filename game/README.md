# 폐허의 거점

BuriedTown의 생존 구조와 타르코프의 하이드아웃을 본뜬 텍스트 생존 게임입니다. 브라우저에서 돌아갑니다.

## 실행

이 폴더를 통째로 받은 뒤 `index.html`을 더블클릭하면 됩니다. 설치할 것은 없습니다.
게임은 행동할 때마다 브라우저에 자동 저장됩니다. 다른 기기로 옮기려면 메뉴의 "세이브 코드"를 쓰세요. 세이브 코드는 전투·사건 중이거나 쓰러진 상태에서는 만들 수 없습니다.
계정 저장을 쓰는 화면에서는, 이 기기의 저장보다 계정 저장이 더 새로우면 덮어쓰기 전에 어느 쪽으로 이어 할지 묻습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `data.js` | 모든 수치: 아이템, 지역, 위험도, 중량 단계, 생존 수치 속도, 적, 디버프, 랜덤 이벤트, 스킬, 스토리 문장, 인물별 메모, 라디오 방송 편성(일어난 일에 반응하는 방송 포함), 인연(만나서 돕는 사람들), 장소마다 보이는 흔적, 시설, 제작법, 숨길 곳, 장비 해체 재료, 떠돌이 상인 거래(`trades`, `trader`), 총기 부착물(아이템 `cat: 'mod'`, 총의 `slots`, 총소리 `combat.noiseMinutes`·`noiseMult`), 의뢰 사슬(`story.bonds`의 `steps`·`obj`·`shop`), 거주민(`story.residents`), 고물상(`story.crow`), 탈출(`story.escape`), 엔딩(`story.endings`) |
| `game.js` | 게임 로직과 화면 |
| `codex.js` | 아이템 도감: data.js에서 제작 가능 여부와 얻는 곳(장소별·적별 확률, 해체, 상인, 사건)을 열 때마다 계산한다. 게임 메뉴와 codex.html이 같이 쓴다 |
| `codex.html` | 아이템 도감만 따로 여는 페이지 (data.js를 바로 읽으므로 수치를 바꾸면 같이 바뀐다) |
| `style.css` | 디자인 |
| `index.html` | 페이지 뼈대 |

밸런스를 바꾸려면 `data.js`만 고치고 새로고침하면 됩니다.

## 의뢰와 엔딩

기록과 라디오로 알게 된 사람들(인연)은 타르코프 상인처럼 의뢰를 이어서 준다. 메뉴 → 기록 → 인연·의뢰에서 진행 상황을 본다.

- **의뢰 목표** (`obj`): 처치(`kill`, 장소·적 지정 가능), 수색(`search`), 찾기(`find`, 수색할 때 확률로), 장소에서 하는 일(`place`, 그 장소에 버튼이 생긴다), 기다리기(`days`), 조건(`cond`). 목표를 다 채워야 보고 선택지(`obj: true`)가 열린다.
- **신뢰와 거래** (`shop`): 의뢰를 하나 끝낼 때마다 신뢰가 1 오르고, `at` 이상이면 그 거래가 열린다. 같은 거래는 하루 한 번.
- **어두운 선택** (`dark: true`): 그 사람을 해친다. 이기면 의뢰가 끊기고 살해 수가 오른다. 한 명이라도 해치면 아무도 거점에 들어오지 않는다.
- **거주민**: 이서윤(의무 · 거점에서 쉬는 동안 감염이 퍼지지 않음), 한지수(날마다 물건이 남은 곳 소식), 정은희와 아이들(시설 공사·생산 속도 증가, 침대 2칸), 김도현과 김도희(밤마다 주변 수색, 조리 속도·음식 효과 증가). 침대 레벨만큼 자리가 있다. 먹을 것과 물은 거주민 목록에서 직접 나눠 준다. 굶으면 도움이 멈추고, 사흘 굶으면 원래 있던 곳으로 돌아간다(다시 데려올 수 있다).
- **고물상 까마귀**: 아무 곳에서나 수색하다 보면 까마귀 쪽지가 나온다. 3장을 모아 거점 철문에 표식을 그리면 다음 날부터 날마다 8~20시에 찾아온다. 하루 4가지 물건을 들고 오고, 신뢰가 오르면 더 좋은 물건이 섞인다.
- **탈출**: 병원의 환자 이송 기록, 군사기지의 수송 계획서, 라디오의 남부 사령부 방송(군 주파수 또는 97.5 MHz 80일째)을 모두 모으면 거점에서 남부 사령부에 연락할 수 있다. 그다음 떠날지 남을지 고른다.

| 엔딩 | 조건 |
|---|---|
| 그들이 되다 | 감염으로 쓰러진다 |
| 생존자 | 탈출하지 않고 남는다 |
| 구원자 | 모든 의뢰 완료, 이서윤·한지수·정은희와 아이들·김도현과 김도희가 거점에 산다, 탈출한다 |
| 떠난 자 | 구원자 조건 없이 탈출한다 |
| 추락하다 | 사람을 3명 이상 해친다 |
| 치료제 (숨은 엔딩) | 기록을 전부 모으고 김정우의 연구를 끝까지 돕고 탈출한다 |

엔딩을 본 뒤에는 새 게임을 시작하거나 그대로 계속할 수 있다. 본 엔딩은 타이틀 화면에 남는다.

## 개발 단계

1. 이동, 수색, 생존 수치, 중량
2. 확률 전투, 디버프, 무기·방어구, 랜덤 이벤트
3. 스킬 성장 (힘, 지구력, 체력, 집중력, 스트레스 저항력, 신진대사, 지능 / 최대 35레벨), 스토리, 음식 버프
4. 하이드아웃 시설, 업그레이드, 제작, 생산
5. **의뢰 사슬, 거주민, 탈출과 엔딩** ← 지금
6. 밤 습격, 밸런스 조정
