# 폐허의 거점

BuriedTown의 생존 구조와 타르코프의 하이드아웃을 본뜬 텍스트 생존 게임입니다. 브라우저에서 돌아갑니다.

## 실행

이 폴더를 통째로 받은 뒤 `index.html`을 더블클릭하면 됩니다. 설치할 것은 없습니다.
게임은 행동할 때마다 브라우저에 자동 저장됩니다. 다른 기기로 옮기려면 메뉴의 "세이브 코드"를 쓰세요.

## 파일

| 파일 | 내용 |
|---|---|
| `data.js` | 모든 수치: 아이템, 지역, 위험도, 중량 단계, 생존 수치 속도 |
| `game.js` | 게임 로직과 화면 |
| `style.css` | 디자인 |
| `index.html` | 페이지 뼈대 |

밸런스를 바꾸려면 `data.js`만 고치고 새로고침하면 됩니다.

## 개발 단계

1. **이동, 수색, 생존 수치, 중량** ← 지금
2. 확률 전투, 디버프, 무기·방어구
3. 스킬 성장 (힘, 지구력, 체력, 집중력, 스트레스 저항력 / 최대 35레벨)
4. 하이드아웃 시설, 업그레이드, 제작, 생산
5. 밤 습격, 밸런스 조정
